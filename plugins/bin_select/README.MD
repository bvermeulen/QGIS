# plugin picture_select

Will select the nearest bin on the canvas and will display offset, spider and rose diagrams in a seperate window

Click with mouse on the canvas and to select the nearest bin

<img src="canvas_selected_bin.PNG" alt="drawing" width="700"/>

The selected picture is shown in a seperate window and you can toggle through the list of pictures either by the arrow keys or by pressing buttons.
