# plugin Seismic Bin Attributes and Binning

Click with the mouse on the canvas to select the nearest bin. A seperate window pop up that displays offset, spider and rose diagrams. Change another bin manually by typing different bin numbers seperated by space or comma.

By pressing the button "Bin traces" this will bin traces useing the selected offset and source indexes.
